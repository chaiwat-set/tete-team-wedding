#TeteFormsHerTeam · 15 มกราคม 2570 · Beelive Convention Hall and Hotel (Hall3) สุรินทร์

## ไฟล์ในโปรเจกต์นี้

```
index.html        ← โครงหน้าเว็บและข้อความ
styles.css        ← รูปแบบและการจัดวาง
script.js         ← ลูกเล่น ตัวนับถอยหลัง และรายชื่อร้าน/ที่เที่ยว
images/           ← รูปและภาพวาดทั้งหมด
  hero.jpg          รูปหน้าปก (จอคอม)
  hero-tall.jpg     รูปหน้าปก (มือถือ)
  hero-sq.jpg       รูปแกลเลอรีช่องที่ 1
  gallery-2.jpg     ← อัปโหลดเพิ่มเอง (ยังไม่มี)
  gallery-3.jpg     ← อัปโหลดเพิ่มเอง (ยังไม่มี)
  *.webp            ตัวเขียนและภาพวาดจากการ์ด
```

## แก้ข้อความ

เปิด `index.html` แล้วค้นหาคำว่า `✏️` จะเจอคำอธิบายกำกับไว้ทุกจุดที่ต้องแก้

ช่องที่ยังรอใส่ข้อมูลจะอยู่ในรูปแบบนี้

```html
<span class="todo">ชื่อ · เบอร์โทร</span>
```

ให้ลบทั้งก้อนนี้ แล้วพิมพ์ข้อมูลจริงแทน เช่น `พี่เอ 081-234-5678`

## เปลี่ยนหรือเพิ่มรูป

อัปโหลดรูปเข้าโฟลเดอร์ `images/` โดยใช้ชื่อไฟล์เดิม ถ้าชื่อซ้ำ รูปเดิมจะถูกแทนที่

ส่วนรูปแกลเลอรี ให้ตั้งชื่อว่า `gallery-2.jpg` และ `gallery-3.jpg` แล้วรูปจะขึ้นเอง

ขนาดที่แนะนำคือกว้างไม่เกิน 1,600 px และไฟล์ไม่เกิน 500 KB เว็บจะได้โหลดเร็วบนมือถือ

## แก้ร้านและที่เที่ยวสุรินทร์

อยู่ในไฟล์ `script.js` ตรง `var G={` โดย 1 ร้านคือ 1 บรรทัด

```js
{n:'ชื่อร้าน', id:'', m:'ที่ตั้ง · เวลาเปิด', d:'คำอธิบายสั้น ๆ'},
```

ช่อง `id` เว้นว่างได้ ปุ่มแผนที่จะค้นจากชื่อร้านให้เอง และอย่าลืมเครื่องหมาย `,` ท้ายบรรทัด
