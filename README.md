## ไฟล์ในโปรเจกต์นี้

```
index.html                 ← โครงหน้าเว็บและข้อความ
styles.css                 ← รูปแบบและการจัดวาง
script.js                  ← ค่าที่แก้บ่อยอยู่บนสุด: ลิงก์ RSVP และรายชื่อรูปแกลเลอรี
surin-places.csv            ← รายชื่อร้าน/ที่เที่ยวที่แสดงบนแผนที่และการ์ดแนะนำ
google-apps-script.gs      ← โค้ดสำหรับวางใน Google Sheet (ไม่ต้องอัปโหลดขึ้น GitHub ก็ได้)
surin-places-template.csv  ← ตารางร้าน/ที่เที่ยวชุดปัจจุบัน ใช้เป็นแม่แบบเพิ่มข้อมูล
images/
  hero.jpg, hero-tall.jpg  รูปหน้าปก (จอคอม / มือถือ)
  gallery/                 รูปและวิดีโอในแกลเลอรี
  scene-bg.jpg, -m.jpg     วิวท้ายเว็บ (จอคอม / มือถือ)
  flowers-cream.webp       ช่อดอกไม้สีครีมในส่วน Thank you
  *.webp                   ตัวเขียนและภาพวาดจากการ์ด
```

## แก้ข้อความ

เปิด `index.html` แล้วค้นหาคำว่า `✏️` จะเจอคำอธิบายกำกับไว้ทุกจุด
ช่องที่รอใส่ข้อมูลหน้าตาแบบนี้ `<span class="todo">วันที่ตอบรับ</span>` ให้ลบทั้งก้อนแล้วพิมพ์ข้อมูลจริงแทน

## แกลเลอรี (ปัดข้าง วนได้ กดดูภาพใหญ่ได้)

ไฟล์อยู่ใน `images/gallery/`
- รูปแต่ละรูปมี 2 ไฟล์: `01.jpg` (ภาพใหญ่ กว้างหรือสูง 2,000 px) และ `01-sm.jpg` (ภาพเล็ก 1,000 px)
- วิดีโอ: `00.mp4`, `00.webm` และ `00-poster.jpg`

ลำดับและรายการอยู่ใน `script.js` ตรง `var GALLERY = [`
- สลับลำดับ: ย้ายบรรทัดขึ้นลง
- เพิ่มรูป: อัปโหลด 2 ไฟล์ (ภาพใหญ่ + `-sm`) แล้วเพิ่มบรรทัด `{src:'27', w:2, h:3},` (w/h คือสัดส่วน แนวตั้ง 2,3 แนวนอน 3,2)
- ถ้าอยากให้ช่วยย่อรูปให้ ส่งรูปมาในแชตได้

## เชื่อมฟอร์มตอบรับกับ Google Sheet

ตอนนี้เชื่อมกับไฟล์ **T&T_Wedding Planner** (Google Sheet) เรียบร้อยแล้ว ขั้นตอนด้านล่างใช้เมื่อต้องตั้งค่าใหม่เท่านั้น

1. ในไฟล์ Google Sheet ไปที่เมนู **ส่วนขยาย → Apps Script** แล้วลบโค้ดเดิมทิ้ง วางโค้ดจาก `google-apps-script.gs` แล้วกดบันทึก
2. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่** แล้วตั้งค่าดังนี้
   - ประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. กดอนุญาตสิทธิ์ แล้ว copy **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
4. ใน `script.js` วางลิงก์ที่ได้ในบรรทัด `var RSVP_URL = '...';`

เมื่อแขกกดส่ง ข้อมูลจะเข้าแท็บ `[Respond]Guest list` ทันที โดยหัวคอลัมน์มีดังนี้
วันเวลาที่ตอบ · ชื่อ-นามสกุล · สถานะ · จำนวนคน · ช่วงที่ร่วม · ข้อความถึงบ่าวสาว

- ถ้าแท็บยังว่าง สคริปต์จะสร้างหัวคอลัมน์ให้เองตอนมีคนตอบครั้งแรก
- ถ้าเพิ่มคอลัมน์ของตัวเองภายหลัง สคริปต์จะเขียนเฉพาะคอลัมน์ที่ชื่อตรงกันเท่านั้น
- ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้องกด Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่ ทุกครั้ง

ถ้า `RSVP_URL` ยังว่าง หรือส่งไม่สำเร็จ ฟอร์มจะให้แขกส่งข้อความทาง LINE แทน

## ร้านและที่เที่ยวสุรินทร์

แก้รายการใน `surin-places.csv` โดยเพิ่มหรือแก้ 1 สถานที่ต่อ 1 แถว ห้ามลบแถวหัวตาราง และใส่ข้อมูลตามคอลัมน์นี้:

`category,name,lat,lng,place_id,meta,description`

- `category` ต้องเป็น `ร้านกาแฟ`, `ร้านมัจฉะ`, `ร้านอาหาร` หรือ `ที่เที่ยว`
- `lat` / `lng` ใช้กำหนดพิกัดหมุดบนแผนที่
- `place_id` เป็น Google Place ID (เว้นว่างได้)
- ถ้าข้อความมีเครื่องหมายจุลภาค ให้ครอบข้อความนั้นด้วยเครื่องหมายคำพูดคู่ (`"..."`)

เว็บโหลดไฟล์ CSV จากเซิร์ฟเวอร์ ดังนั้นให้เปิดผ่านเว็บเซิร์ฟเวอร์หรือ URL ของเว็บไซต์ ไม่ใช่เปิด `index.html` โดยตรงจาก `file://`

วิธีหาพิกัด: เปิด Google Maps แล้วคลิกขวาที่ตำแหน่งร้าน จะเห็นตัวเลข เช่น `14.8786, 103.5052` กดตัวเลขนั้นเพื่อ copy
